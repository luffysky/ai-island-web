## 0. 定位
> **你的數位分身，替你動手。** 交代目標，分身一步步規劃、用工具查資料/操作、記得你、跨裝置延續；關鍵動作先問過你才做。

- 差異化不是「操作能力最強」，而是**最透明、最可控、最適合新手、且長在 AI 島生態裡**（懂你的學習/作品/機會）。
- 核心價值：**權限透明、步驟可視化、失敗可回復、免費優先省成本、用 Agent → 學會建 Agent**。
- 一句話：現在的 AI 回答問題，分身替你完成任務；擋住一般人用 Agent 的不是模型，是**不敢授權、不懂操作、無法判斷風險**——分身島讓每個人安全駕馭。

## 2. 架構
```text
使用者（AI 島網頁 / 手機 / 語音）
   │ 自然語言目標
   ▼
Agent Core（server-side）：拆解(L1) → planner → 權限 → 執行 → 觀察 → 反思(L3) → 重試/下一步/完成
   │                       ＋最大步數＋狀態機＋中止＋免費優先模型路由
   ├── Tool Registry（風險 read/write/dangerous、平台、JSON schema）
   ├── Approval Engine（L0–L4；write/dangerous 逐次確認、動作/位置/影響/可復原）
   └── 記憶（agent_threads 前文 + agent_memory 長期）
   │
三種執行面：
   A 雲端工具（server；web.search/fetch、算數/日期/JSON、島內、MCP）── 手機單獨可跑
   B 雲端沙盒（⬜ 臨時容器，沒 PC 也能跑本機類任務 = Phase E）
   C 本機 Bridge（桌面助手：檔案/指令/瀏覽器；電腦沒開→排隊等上線）
```

**通訊**：Bridge↔雲端走 `agent_device_calls` 佇列＋輪詢（裝置無關，手機/桌面/Android 同一套）。

## 6. 引擎路線（L1→L5，逼近「什麼都能做」）
六支柱：手(工具)、腦(規劃)、眼(反思)、記憶、手煞車(人在迴圈)、調度(多代理)。
- **L1 拆解** ✅ · **L3 反思** ✅ · **L2 Tool First** ✅（安全計算/搜尋）
- **L2 真手** 🚧：伺服器 Playwright 瀏覽器（不需你電腦、能點填登入跑JS）＋ isolated-vm 真 JS 沙盒（需改 Docker 裝 Chromium/native module）＋ 外部容器（Python，= Phase E 雲端沙盒）。
- **L4 技能合成** ⬜：agent 遇到沒有的能力當場建一個 skill 註冊。
- **L5 多代理／數位員工** ⬜：經理 agent 拆派給專才 sub-agent（研究/寫碼/設計/驗證）並行做、彙整。
- L5 之後：從歷史學習、預算感知、主動代理、串流部分成果、工具自動發現、可觀測性。

## 7. 數位員工 / AI 公司（世界觀，對應 L5）
登入不是聊天框，而是「你有一家 AI 公司」：CEO(你)＋多聞(PM)/Hunter(機會獵人)/Coder/Writer/Designer/Analyst/QA…全 AI、可派工。
- **能力非職位**：員工是能力向量，工作只是今天派的任務。
- 遊戲化：升級/裝技能/招募/培訓/KPI/成本 Dashboard/AI 開會/AI 辦公室——**但務必真做事**，動畫只是可視化。
- 三種員工：通用／專業／**你訓練的**（讀你文件流程、越來越像你的資深員工＝護城河）。
