# 機會島（Opportunity Island / Opportunity OS）— 完整功能規格

> 來源：`docs/待閱/機會島.md`（林董 × GPT 前前後後整段討論）。本檔把裡面**提到過的所有功能**提煉、去重、分類，
> 補上資料模型與分版本落地。定位不是「競賽搜尋」，而是 **每個人的人生機會作業系統**；競賽只是第一個模組。
> 做在 AI 島裡（要用＝要註冊 AI 島），成為 AI 島的核心島嶼與**最強獲客入口**。

## 4. AI 功能全集（提煉自 md 前後所有段落）
**理解使用者（四種深度）**
- 純搜尋（零 AI）→ 問卷（5 分鐘）→ AI 聊天追問（最推）→ 直接分析上傳物。

**分析與推薦**
- AI 推薦（輸入條件 → 推 N 個，附**推薦原因 + 符合率 %**，透明不黑箱，也列「不推薦＋原因」）
- AI 分析：網站 / GitHub Repo / PDF / Pitch Deck / 商業計畫 / 履歷 / 作品集 / 影片 → 判類型與可投清單
- AI 作品成熟度（技術 / 市場 / 商業 / 創新 / 完成度 各給分）
- AI 競爭力分析（原「得獎率」改名，避免誤導；附符合/缺項與參考分數）
- AI 缺件分析（缺 Pitch / Demo / 財務 / 商業模式 / 使用者數據）
- AI 缺點分析（歷屆評審最常扣分項 → 提醒）
- AI 對手分析（去年第一名拆解）

**生成與陪跑**
- AI 生成：Pitch / 商業計畫 / 簡報 / 海報 / 介紹影片腳本
- AI 讀規則（長 PDF 摘要）· AI 聊天問「我可以參加嗎」
- AI 模擬評審（像真人連問）· AI 評分（創新/市場/Demo/Pitch/影片各分 → 建議先補哪項）
- AI 學習（一直輸 → 分析原因 → 推薦 AI 島課程，形成學習閉環）
- AI 路線圖 / AI 生涯（三年內創業 → 逐年規劃該投什麼）
- AI 自動代辦（一鍵建報名清單、截止提醒、需備文件、打勾）
- （V 後段、需授權且遵守主辦條款）AI 代報名：讀規則 → 對照資料 → 列缺件 → 產報名回答初稿 → 建投件時程

**知識庫 / 資料**
- AI 知識庫（歷年得獎作品學起來）· AI 歷史（近十年獎金/規則）· AI 新聞（新競賽推播）· AI 排行榜（最大獎金 / 最高 CP / 最好得）

## 5. 個人化區（登入才有）
- **我的機會**：今天新增 N 個 / 推薦 N 個 / 截止倒數 / 缺什麼資料。每個人都不同。
- **我的航線 🧭**（不叫收藏）：像航海王紀錄指針，完成一站下一站自動亮。
- **機會地圖 🏝️**：用地圖不是列表，點島嶼進去看該類所有機會。
- **AI 島專屬頁（只有你看得到）**：AI 島內部作品檔案，自動分析目前功能 → 對照所有競賽資格 → 顯示新符合/截止倒數/缺件，依進度排序。
- **能力圖譜（Capability Graph）**：不是猜你適合什麼，而是把「你擁有什麼（技能/資源/身分/目標/作品）」對比「競賽需要什麼」→ 推薦有依據、隨你新增作品越來越準。
- **個人成長時間軸**：學習 → 建作品 → 投競賽 → 得獎 → 創業 → 求職，形成完整履歷 + 成就/積分/徽章/排行（遊戲化）。
- **AI 配對組隊**：設定缺前端/設計/PM/行銷 → 依技能/興趣/所在地/投入時間媒合隊友。
- **機會訂閱**：追蹤「條件」（AI+台灣+免費+10萬+）而非單一網站，符合就推播。

## 6. 多聞雷達（爬蟲 + 變動偵測 + 通知）
四層系統（md 明確拆過）：
1. **來源掃描層**：政府/獎金獵人/大學/新創基地/國際/企業活動頁（先 API/RSS/sitemap/Email，爬蟲當最後手段、守 robots/rate limit）。
2. **變動偵測層**：保存 `raw_html_hash` / `normalized_text_hash` / `structured_fields_hash` 三種；只有**結構化欄位**（截止/獎金/資格/PDF）變才通知，換 banner 不吵。
3. **AI 結構化層**：抽名稱/主辦/起訖/獎金/報名費/資格/是否 Demo/Pitch/應備文件/連結；**保存原文證據 + 來源段落 + 信心分數 + 人工確認狀態**（每欄可點回原文，防「有自信地報錯截止日」）。
4. **通知與任務層**：新競賽 / 截止異動 / 剩 30·14·7·3·1 天 / 缺件提醒 / 自動建投件任務。管道：站內 / Email / LINE / Discord。
- **Cron 分頻**：官方首頁每 6h、已開放每 3h、距截止 14 天內每 1h、大學頁每 12h、國際每 6–12h、已截止每 7 天、年度賽開放前每 6h。技術：Playwright + Cheerio + n8n/GitHub Actions + Supabase + Sentry + 自建 crawl_logs。

## 9. 分層收費（依「價值」不是「功能數」）
- **免費**：搜尋 / 篩選 / 我的航線 / 基本截止提醒 / AI 摘要 / 基本 AI 推薦（找得到機會）。
- **Pro（月費）**：AI 作品分析 / 深度推薦 / 競爭力分析 / 缺件分析 / 成熟度 / 模擬評審 / AI 生成 / 多聞雷達 / 即時通知（知道自己最適合哪些、AI 幫你準備）。
- **Team**：多作品 / 多人 / 任務分工 / 留言 / 版本 / AI 會議（管理投件流程）。
- **Enterprise**：API / 白牌 / 學校 / 政府 / 加速器 / 內部競賽。
- 原則：免費版仍很好用（累積用戶），付費是因為 AI 幫你**省時間、提高成功率**，不是把基本功能鎖起來。

## 10. 重新分版本（把 md 後段全部納入後重排）
- **V1 — 找得到（可上線的最小閉環）**：opportunities(競賽) 資料表 + 搜尋/篩選 + 詳情頁 + 我的航線 + 截止提醒 + AI 規則摘要。先 20–30 個高價值來源、**人工/半自動維護**，先不做全自動爬蟲。
- **V2 — 找得準（AI 推薦）**：問卷 + AI 聊天追問 + 能力圖譜 + AI 推薦（附原因/符合率）+ 機會訂閱 + AI 島專屬頁。
- **V3 — 幫你贏（AI 陪跑）**：作品分析(網站/GitHub/PDF/PitchDeck) + 成熟度 + 競爭力分析 + 缺件/缺點分析 + AI 生成 + 模擬評審 + AI 自動代辦 + Calendar/通知(LINE/Email/Discord)。

- **V5 — Opportunity OS（擴類 + 生態）**：補助/獎學金/創投/工作/實習/海外/證照/標案/徵件十層 + AI 配對組隊 + 成長時間軸/成就 + Team/Enterprise/API/白牌 + AI 代報名（授權且合規）。

## 10.5 Agent2.md 追加（散步腦力激盪提煉）

### A. 參賽成本篩選（⭐⭐⭐⭐⭐——比獎金還重要，已 V1 部分落地）
使用者常常不是不想投，而是不知道要投入多少。每個機會除了獎金，標示「成本」：
- 🎤 是否要上台 Pitch · 💬 是否有 QA 問答 · ✈️ 是否到現場 · 🌐 全程線上 · 👥 是否組隊 · 💰 報名費 · 🎥 是否要影片 · 📄 要幾份文件 · ⏱️ AI 預估準備時間（2 小時／2 天／2 週）。
- 篩選：「怕上台→排除所有 Pitch」「只接受線上」。**已建欄位** `is_online/requires_qa/requires_team/prep_effort`＋「免上台/線上」篩選（`opportunity_cost_migration.sql`）。V3 補「AI 預估準備時間」。
- 分類參考：①只交作品（不用上台）②初賽交件·決賽上台（AI 島最常見）③現場 Demo（Hackathon）④全程線上。

### B. AI 模擬評審 / 模擬競賽（V3 獨家功能）
完整流程，不只聊天：`歡迎參加 XX 決賽 → 倒數 → 你 Pitch（AI 全程錄音/計時）→ 時間到 → Q&A`。
- **多人格 AI 評審**：👨‍💻技術（資料庫/API/擴充）· 👩‍💼商業（賺錢/市場）· 🧑‍💼投資人（為何投你）· 🙋使用者（為何我要用）· 😈酸民（ChatGPT 不就能做？）—— 輪流**追問**、像真人。
- **AI 評分**：語速/自信/口頭禪（抓「呃…那個…」）/重點/時間超時；總分＋優點＋弱點＋哪題答最好＋哪題易扣分＋簡報修改建議。
- **練習階梯**：電梯簡報 30 秒 → 1/3/5/10 分鐘；角色扮演（國中生/阿嬤/投資人/工程師都聽得懂＝真的懂）。
- 受眾遠大於 AI 島：準備競賽/畢業專題/求職簡報的人都會用。

### C. Opportunity Pipeline（機會流水線——機會島真正的護城河）
不要停在「推薦給你」，做成完整閉環：
```
發現機會 → AI 評估適合度 → 建立專案 → 拆解任務 → 準備文件 → 補齊缺件 → 模擬評審 → 提交(使用者確認/授權) → 追蹤結果 → 整理經驗 → 累積到作品履歷
```
別家幫你「找到機會」；AI 島幫你「把握機會、完成整個流程」。這條 pipeline 由**分身島 Agent（數位員工）**驅動——Hunter 找、PM 建任務、Writer 寫企劃、Designer 做簡報、Research 查歷屆、Lawyer 檢查資格、QA 檢查缺件、CEO(你) 確認送件。

### D. 社群經驗層（做到業界最強的關鍵，不只官方資訊）
每個機會除官方規則，讓歷屆參賽者分享：Pitch 難不難／評審會不會刁鑽／準備多久夠／去年常被問什麼／整體推薦度。官方說「上台 8 分鐘」，參賽者會說「評審其實最在意 Demo 不是投影片」——這種經驗多數平台都缺。

## 11. 風險 / 但書（md 已點、務必守）
- **資料可靠性是最大坑**（不是爬蟲寫不出來）：日期藏圖片 / 只有 PDF / Google 表單報名 / 獎金在附件第 17 頁 / 過期沒下架 / 沿用去年網址 → 需 selector fallback + PDF 解析 + 日期合理性檢查 + 年份辨識 + **人工覆核佇列**。
- **LLM 會抽錯欄位**（「總獎金 100 萬」誤判「第一名 100 萬」）→ 每欄存原文證據 + 信心分數 + 人工確認，可點回原文。
- **分數用規則引擎算**、不讓模型每天心情不同。**得獎率一律叫「競爭力/參考分數」**，不保證。
- 不要一開始就做「全部」——V1 只做「幫使用者找到適合自己的免費競賽」，跑通「抓取→辨識→變動→通知→人工覆核」整條鏈再擴。
