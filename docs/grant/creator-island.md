# 創作者島嶼 Creator Island — AI 島的第二根支柱

> 本檔為「Creator Island」亮點專章，供計畫書 ch1（摘要）、ch3（產品）、ch5（商業模式）、pitch 引用，統一口徑。
> 成熟度分層：`✅ 已上線`／`🟡 半成品`／`⚠️ 紅線`（demo 避免展示）。現況口徑一律依 `ch0-baseline-honesty.md`（pre-launch / pre-revenue、註冊 17、營收 0、UGC 多為種子）。

---

## 1. 一句話

**Creator Island 是 AI 島的第二座島 —— 讓一般人也能用 AI 把腦中的想法變成真的作品。**

如果「學習島」降低的是人對**寫程式**的恐懼，那 Creator Island 降低的是人對**用 AI 創作**的恐懼。兩座島，同一個靈魂：**在 AI 時代，把「可怕、不敢碰」的東西，變成「敢動手、做得出來」。** 這正是 AI 島跟「AI 化程式補習班」最不一樣的地方 —— 我們不只教人「學」，也陪人「做」。

## 2. 為什麼它是亮點，而不是附屬功能

- **它讓平台從「學習工具」變成「創作場域」**：使用者不是學完就離開，而是把學到的、想到的，在同一個世界裡做成作品、分享、甚至交易。學習 → 產出 → 分享形成留存動機。
- **它擴大了受眾**：不只寫程式的人。想寫小說、做音樂、寫文案、發想企劃的人，都能用綠寶（創作夥伴）把碎片變成作品。這是「AI 時代學習年齡提前 / 受眾擴大」願景的具體載體。
- **它跟學習島共用同一套 AI 基建**：同一組模型路由 / 快取 / 配額 / 記憶撐兩條產品線 —— 這是**成本上的優勢**，不是兩份負擔（見第 5 節與 ch6）。

## 3. 現在做出了什麼（誠實分層）

| 能力 | 狀態 | 說明 |
| --- | --- | --- |
| 創作夥伴綠寶（Creator 版 AI） | ✅ 已上線 | 陪發想、把零散碎片變成作品、給可立刻動手的創作方向（音樂 / 小說 / 故事 / 詩 / 文案），可看圖給靈感（多模態） |
| 創作者部落格 / 作品發佈 | ✅ 已上線 | 創作者可開部落格、發佈作品；站上已有創作者住民（蘇晚 / 林之遠 / 何默 / 江見）示範內容 |

| 提領 payout | 🟡 半成品 | `method=manual`、**人工審核、未接金流、不會自動入帳**；商業登記完成前無法真正撥款（同 ch0 口徑） |
| 創作者成本儀表 / 家譜等周邊 | 🟡 / ⚠️ | 部分為 stub 或未完成（詳 `tech-inventory.md`）；demo 避免展示 |

> 誠實界定：Creator Island 的「創作 → 分享 → 變現」**路徑已串接、收款能力已建置**，但**變現閉環尚未經市場驗證** —— 目前市集無自然交易、提領為人工流程、營收為 0。**不可寫成「創作變現閉環已完成」**；正確口徑是「路徑已串接、閉環假設待市場驗證」。

## 4. 本計畫要驗證 / 深化的（研發題目，而非「已完成」）

Creator Island 織進計畫書的三大聚焦，而不是另立門派：

1. **AI 陪伴品質（與學習島共題）**：創作夥伴綠寶能不能接住使用者當下的靈感與卡點、依需求給「可立刻動手」而非空泛的建議、看圖給對的方向 —— 這是「AI 教學 / 陪伴品質」研發題目的創作端。
2. **AI 成本與品質平衡**：兩座島共用同一套模型路由 / 快取 / 配額；本計畫驗證「創作型長對話」的每位活躍創作者推理成本與品質取捨。
3. **真實市場驗證**：學習島驗完課 / 留存 / 付費意願；創作島驗**創作完成率、作品產出量、自然 UGC 與市集自然交易**。

## 5. 與學習島的關係（一張圖說完）

```
                 AI 島（同一個靈魂：降低 AI 時代的恐懼）
        ┌───────────────────────┬───────────────────────┐
   🏝️ 學習島                                      🎨 創作島 Creator Island
   降低對「寫程式」的恐懼                          降低對「用 AI 創作」的恐懼
   不敢開始 → 能獨立解題                           想法在腦中 → 做成作品、分享
        └───────────── 共用同一套 AI 基建 ─────────────┘
        （模型路由 / 語意快取 / 配額 / 跨對話記憶 / Z 幣經濟）
```

## 6. 一句話擺進計畫書定位

> AI 島是一套 AI 陪伴式的「學習 × 創作」系統：用學習脈絡理解與分程度回應，降低初學者從「不敢開始」到「能獨立解題」的門檻；並透過**創作者島嶼**，讓一般人也能用 AI 把想法變成作品 —— 共同降低 AI 時代對「學」與「做」的恐懼。
