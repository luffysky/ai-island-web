# SWOT 分析（AI 島）

> 本頁是團隊對自身的策略分析（內部視角），非外部市場數據。
> 市場、競品數字一律沿用計畫書既有的可查證來源（見 `ch2 市場痛點`、`ch7 競品分析`、`tech-inventory 技術盤點`），不另行編造。
> 現況口徑以 `ch0` 為準：**pre-revenue（尚未營收）、少量真實用戶、尚未推廣、尚未完成商業登記與金流開通**。

---

## S — 優勢（Strengths）

以「已在程式碼裡、可驗證」的東西為準（對照 `tech-inventory.md` 的檔案:行號）：

- **自建多供應商 LLM 整合層**：一套閘道（`src/lib/ai-providers.ts`）串接 OpenAI 相容多家供應商，可依成本/可用性智慧路由，不被單一供應商綁死。
- **成本控制三招已落地**：免費供應商輪替、瀏覽器端 WebLLM/WebGPU（在使用者裝置跑、伺服器成本≈0）、語意快取（相似問題不重打 API）。→ 邊際 AI 成本可壓到接近零，直接支撐「免費用戶大方給額度」的商業模式。
- **差異化功能「筆記系統」**：多數競品沒有的結構化學習筆記 + 市集，構成獨立於課程內容的黏著點。
- **零成本四語系內容**：自動翻譯管線（Google-free）讓內容近乎免費地擴到多語，海外市場邊際成本低。
- **求職閉環**：履歷 / 作品集 / 模擬面試串成「學完 → 產出 → 求職」路徑，而非單純看課。
- **第二產品線 Creator Island 已有雛形**：單一團隊、單一技術棧同時養兩條產品線，複用 AI / Z幣 / 帳號系統。
- **開發速度與整合度**：全站自建（課程、AI、遊戲化、社群、後台稽核）耦合度高、迭代快。

## W — 劣勢（Weaknesses）

誠實揭露，與 `ch0` / `ch6` 口徑一致：

- **尚無營收、尚未推廣**：真實活躍用戶極少，產品—市場契合（PMF）尚未驗證。
- **商業登記與金流未開通**：獨資商號登記、金流特約商店（需統編）尚在辦理，目前無法正式收款。
- **單人 / 極小團隊**：開發、內容、營運、客服集中於少數人，是最大瓶頸與風險點（bus factor 低）。
- **AI 成本尚未全面記帳**：並非每個 AI 入口都完整記錄真實 token→成本，難精算單位經濟（已列為最高優先待辦）。
- **部分遊戲化 / 島嶼經濟仍為半成品**：進度多存 localStorage、跨裝置歸零；刷幣去重等伺服器權威驗證未完備。
- **內容深廣度仍在補齊**：章節數雖多，但部分為 AI 草稿待校，體系完整度與競品成熟課程仍有差距。
- **沉浸式 3D 島嶼吃資源**：弱機 / 手機掉幀，需降耗或分流方案。

## O — 機會（Opportunities）

沿用計畫書既有來源（數字見 `ch2` / `ch7`，此處只列策略機會、不重述數字）：

- **政府補助與競賽**：DIGITAL+ 數位服務創新補助、創業競賽，可在 pre-revenue 階段補資金與背書。
- **AI 學習尚無「完整組合」贏家**：競品雖多已有 AI（見 `ch7`），但「AI 導師＋筆記＋遊戲化＋求職閉環」的整包體驗仍有空間。
- **LLM 價格快速下探 + 開源模型可用**：本地/開源模型成熟，讓「免費也給得起 AI」的模式愈來愈可行。
- **多語 = 海外市場**：零成本翻譯讓同一套產品低成本試打非中文市場。
- **創作者經濟**：Creator Island 讓使用者從「學習者」變「產出者/銷售者」，開新收入與留存來源。

## T — 威脅（Threats）

- **大廠與資本雄厚競品**：既有平台（見 `ch7`）挾內容、品牌、資金持續加 AI 功能，可能快速覆蓋差異化。
- **LLM 供應商政策 / 定價 / 模型退役風險**：免費額度收緊、模型下架（如 GitHub Models 於 2026-07-30 退役）會衝擊成本結構與可用性——已用多供應商 + 本地模型分散風險。
- **法遵與資料保護**：個資 / GDPR / 內容審核責任隨用戶成長上升。
- **獲客成本**：無品牌、無預算下，自然流量獲客慢；一旦付費投放，CAC 可能高於早期 LTV。
- **關鍵人風險**：小團隊下，核心成員異動即衝擊全線。

---

## 策略對應（SO / WO / ST / WT）

- **SO（用優勢抓機會）**：以「近零 AI 成本 + 完整組合 + 多語」主打補助/競賽的差異化敘事，並低成本試打海外。
- **WO（補劣勢抓機會）**：用補助資金補「人力、內容校潤、金流開通、AI 記帳」等當前最痛缺口，加速驗證 PMF。
- **ST（用優勢擋威脅）**：多供應商 + 本地模型分散「供應商政策/退役」風險；以整合度與迭代速度應對大廠功能競逐。
- **WT（守住底線）**：先把商業登記/金流/資料保護與伺服器權威驗證補齊，降低法遵與刷幣風險，再談擴張。
