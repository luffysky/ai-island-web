# 獨資商號（行號）登記 — Step-by-Step 清單

> 目的：取得**統一編號**，一次解鎖 ①藍新/綠界正式收款 ②青年創業貸款 ③DIGITAL+ 補助資格。
> 你的情況：一人、資訊軟體服務 → 辦**獨資商號（行號）**最簡單（非公司登記，資本額無下限）。
> 資料來源：經濟部中小及新創企業署、法律百科、史貝斯/宏摩會計等（2026-07 查證；規費/流程以主管機關公告為準）。

## ⏱️ 時間與費用（自辦、可省代辦費）
- **時間**：線上申請約 **3–7 個工作天**、臨櫃約 5–10 天；含稅籍完整跑完約 **3–4 週**。→ **開業/需收款前 2–3 週先辦**。
- **費用**（自辦）：
  - 名稱預查：網路 **NT$150**（臨櫃 NT$300）
  - 商業設立登記：**NT$1,000**（網路申請減二成 = **NT$800**）
  - 刻印章（負責人章 + 商號章）：約 NT$200–500
  - **合計約 NT$1,000–1,500**（找代辦另加約 3,000–8,000，可自辦省下）

## 📄 要準備的文件
- [ ] 申請書（線上系統填）
- [ ] 負責人**身分證明**（身分證正反影本）
- [ ] **資本額證明**（獨資小額可用存摺影本；金額自訂、無下限）
- [ ] **營業所使用權證明**：
  - 自有 → 建物所有權狀影本 + 最近一期**房屋稅單**
  - 租的 → **租賃契約** + **房屋使用同意書**（房東簽）+ 房屋稅單
  - 住家兼營業 → 確認可登記（部分需房東/管委會同意；純線上服務通常可）
- [ ] **印章**：負責人私章 + 商號章（可先刻或核准後刻）

## 🪜 步驟
1. **決定型態**：獨資商號（行號）。
2. **想商號名稱 1–5 個** → 上「**公司與商業及有限合夥登記預查**」線上預查（避免撞名）→ 送正式名稱預查（NT$150）。
   - 名稱建議好記、與品牌相關（可與 AI 島／SnowRealm 呼應）。
3. **決定營業項目**：勾**資訊軟體服務相關**——對應行業別 **J62（電腦程式設計/諮詢）、J63（資訊服務）**（這也是 DIGITAL+ 補助要求的行業別，先掛好）。
4. **辦商業登記**：備文件送**營業所在地縣市政府**（建設局/經濟發展局 商業登記科），或走**經濟部一站式線上申請**（`onestop.nat.gov.tw` / 商工登記公示系統）。
5. **辦稅籍登記**：送**國稅局**（可與商業登記一起或緊接著辦）。
6. **取得統一編號**：完成商業登記 + 稅籍登記後核發。
7. **刻章 + 開營業用帳戶**（銀行，用於金流入帳）。

## ✅ 拿到統編之後（立刻能做）
- [ ] 用**企業會員 + 統編**去**藍新 NewebPay / 綠界 ECPay** 申請**特約商店** → 開通正式收款（解決「請以企業會員註冊」的拒絕）。
- [ ] 評估**青年創業貸款**（29 歲符合；需另上**創業輔導課程 20 小時 / 2 學分**、3 年內有效）。
- [ ] 具備 DIGITAL+「數位服務創新補助」之**行業別 + 登記**資格前提。

## ⚠️ 提醒
- 規費/流程各縣市略有差異，**以主管機關最新公告為準**。
- 純線上服務、住家登記通常可，但**先確認租約/房東是否允許營業登記**。
- 一人自辦完全可行；不確定可找記帳士諮詢（首次諮詢常免費）。
