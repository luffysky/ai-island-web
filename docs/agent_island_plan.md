# Agent 島（行動代理）— 全面重新規劃

> 目標：把 `/agent` 從「單次無狀態任務」升級成一座**能在桌機 / 平板 / 手機都最大化使用**的行動代理島，
> 補上對話延續 + 跨對話記憶（詳細 schema 見 `docs/agent_memory_plan.md`），並解掉「電腦沒開手機就沒用」的致命問題。
> 對標 OpenClaw / NemoClaw，但做它們做不到的事（教育原生 + 生態閉環 + 繁中在地，見 memory 檔）。

---

## 0. 命名（要你拍板）
島宇宙世界觀，代理＝「替你動手做事的數位你」。提案（推薦第一個）：
1. **分身島（Avatar Island）** ⭐ — 「你的數位分身，替你動手」。比「助手」更強、更有主體性，跟通用 claw 助理做出區隔。
2. **代理島（Agent Island）** — 直白好懂。
3. **助手島（Assistant Island）** — 溫和，但偏弱、跟綠寶導師易混。
> 機會島負責「找機會」、分身島負責「動手做」；兩島串起來＝找到機會→分身幫你準備參賽。

---

## 1. 核心重新思考：三種執行面（Execution Surfaces）
現況最大架構缺陷：**所有本機動作都要桌面 Bridge 在線**，電腦一關手機代理就廢。重構成三面：

| 面 | 在哪跑 | 需要 PC 開機？ | 能做什麼 |
|---|---|---|---|
| **A. 雲端工具** | 我們的 server | ❌ 不需要 | web.fetch、我們自家 API、MCP server、辭典、DB 動作、內容生成、機會島查詢 |
| **B. 雲端沙盒**（新增，選配） | 伺服器臨時容器 | ❌ 不需要 | shell / 檔案 / headless 瀏覽器（給沒 PC 的人也能跑「本機類」任務）—— 對標 NemoClaw OpenShell |
| **C. 本機 Bridge** | 使用者電腦 | ✅ 需要 | 讀寫你**自己電腦**的檔案、跑你電腦的指令、開你電腦的瀏覽器（不可被雲端取代的部分） |

**關鍵原則**：一個任務的每一步，**能在雲端做的就在雲端做（A/B）**，只有「非你這台電腦不可」的步驟才走 C。
→ 手機/平板單獨也能跑：web 研究、生成 Pitch/文案、查機會島、呼叫 MCP、管理任務、跑雲端沙盒。**手機不再是廢的。**

---

## 2. 解「電腦沒開，手機代理沒用」（三招並用）
1. **能力分流**：規劃器（planNext）為每步標 `surface: cloud | sandbox | local`。cloud/sandbox 步驟**永遠可跑**；只有 local 步驟需要 Bridge。任務能完成的部分先完成，不會整個卡死。
2. **離線排隊 + 上線續跑**：local 步驟若 Bridge 離線 → 進 `agent_device_calls` 佇列（已有），手機顯示「等你電腦上線」；PC 一開自動接著跑並推播結果。背景任務機制已存在（detached + poll）。
3. **雲端沙盒補位（選配、Pro）**：沒 PC 或不想開機的人，把「本機類」步驟導到伺服器臨時沙盒（限額、隔離、政策路由），手機就能 100% 獨立完成。

---

## 3. 桌面助手 → 真正的「本機 Agent」（#5 加強）
現況桌面 Bridge 只是「被雲端遙控的手」。升級成**本機自主 Agent**：
- **本機自己有規劃迴圈**：斷網 / 純本機任務也能跑（本機 LLM 或帶 key 的雲端 LLM），不必每步往返雲端。
- **更多本機能力（Skills）**：檔案批次處理、跑測試/建置、git、截圖、本機瀏覽器自動化（Playwright）、排程、監看資料夾、對接本機 App。
- **雲↔本機同一套 Skills 介面**：雲端規劃、本機執行；或本機獨立規劃執行；結果回寫雲端對話串（記憶一致）。
- **安全**：延用白名單 + 逐步確認 + 目錄限定；本機 Agent 也套政策（對標 NemoClaw sandbox 政策路由）。

## 4. 對話延續 + 跨對話記憶（摘要，細節見 agent_memory_plan.md）
- `agent_threads` 把多個 task 串成連續對話；planNext 帶入「本串前文 + 長期記憶 + 跨對話語意檢索」。
- `agent_memory`（fact/preference/skill/project/goal）跨對話記得你 → 文案小編不再每次重問。
- pgvector 語意檢索舊對話 → 「像上次那個活動再來一版」拉得到。

## 5. 跨裝置 UX（桌機 / 平板 / 手機都最大化）
- **`/agent` 響應式聊天島**：手機單欄（對話串抽屜 + 底部輸入 + 語音）、平板雙欄、桌機三欄（串列/對話/工具與裝置面板）。
- **手機優先控制**：語音輸入、逐步批准（Web Push 通知即批准）、背景任務 + 完成推播（已有基礎）。
- **裝置切換無縫**：同一 thread 在手機開任務 → 桌機接著看/續聊（雲端狀態單一來源）。
- **能力提示**：某步需要本機時，UI 明說「這步要你的電腦（桌面助手）」並給一鍵喚起 / 排隊選項，而不是默默失敗。

## 7. 分階段
- **Phase A｜對話延續**：threads + priorContext(短期) + 響應式聊天島 UI。
- **Phase B｜跨裝置執行分流**：planNext 標 surface、cloud/sandbox 步驟免 Bridge、local 步驟排隊+上線續跑 → **手機單獨可用**。
- **Phase C｜長期記憶 + 跨對話檢索**：agent_memory + 抽取 + pgvector。
- **Phase D｜本機 Agent 加強**：桌面助手自帶規劃迴圈 + 更多本機 Skills + 政策。
- **Phase E｜雲端沙盒（選配 Pro）**：沒 PC 也能跑本機類任務。
- **Phase F｜護城河整合**：接章節掌握度 / 作品檔案 / 機會島 / Z幣。

## 9. 「什麼任務都能完成的引擎」怎麼做（林董提問的完整回答）

先講實話：**沒有任何引擎能『literally 完成任何任務』**——OpenClaw / NemoClaw / Devin 都做不到。差別在於**離『任何任務』有多近、失敗時多會自救**。要逼近它，靠的不是單一魔法，而是六根支柱一起補強。我們現在有骨架（ReAct 迴圈、工具、逐步批准、記憶、對話延續、免費優先＋自動升級、達上限合成最終答案），下面是把它升級成「幾乎什麼都能做」的路線。

### 六根支柱（缺一就會卡）
1. **手（能執行的工具面）**：Agent 只能做「工具允許的事」。要接近『任何任務』就要有真正的手——真瀏覽器（不是只抓 HTML，是能點/填/登入/跑 JS 的 headless 瀏覽器）、程式沙盒（跑生成的 Python/JS 做運算/資料處理）、檔案/shell（本機 Bridge 已有）、無限外部工具（MCP）、電腦操作（截圖＋點座標）。**大多數真實任務是「網頁上的操作」**，所以真瀏覽器是投報率最高的一根。
2. **腦（規劃）**：目前是單層 ReAct（想一步做一步）。升級成 **Planner–Executor 階層 + 任務拆解**：先把大目標拆成一張子任務清單（task tree），逐項執行、逐項打勾；沒全部完成不算 done。這是「能不能完成複雜任務」最大的槓桿。
3. **眼（驗證/反思）**：每個子任務做完，一個 critic 檢查「真的達標了嗎」；沒達標就 replan 換做法。**自我修復**讓它不會一條路走到黑。
4. **記憶（脈絡）**：長期記憶（已有）＋對當前任務的 RAG（檢索相關文件/網頁/過去成功的做法）。做過的成功計畫可快取重用。
5. **手煞車（人在迴圈）**：模糊/高風險步驟問使用者（approvals 已有）。這不是弱點，是「敢放它做危險事」的前提。
6. **調度（多代理）**：真正難的任務用「經理 agent 拆派給專才 sub-agent（研究員/工程師/寫手/驗證者）並行做」——就是 Workflow 那套。可靠度最高。

### 分級路線（每級都是可獨立上線的引擎升級）
- **L1 · 拆解引擎**：加頂層 planner 把 goal 拆成子任務 checklist、逐項執行＋打勾、全部驗證才 done。→ 從「單步反應」變「會做專案」。**最該先做。**
- **L2 · 真手**：伺服器端 headless 瀏覽器（Playwright on server，不需使用者電腦）＋程式沙盒（跑生成碼）。→ 解鎖絕大多數「網頁操作 / 要算東西」的任務。這也接上 §1-B 雲端沙盒。
- **L3 · 反思迴圈**：每子任務後 critic 驗證、失敗自動 replan。→ 自我修復、少爛尾。
- **L4 · 無限工具**：MCP 接任何外部服務（已有骨架）＋ **技能合成**（agent 遇到沒有的能力，當場寫一個 skill 註冊起來）。→ 能力可自我擴張。
- **L5 · 多代理調度**：經理 agent 並行派工給專才 sub-agent（研究/寫碼/驗證），彙整結果。→ 逼近「什麼都能做」的可靠度上限。

### 還能再怎麼升級（L5 之後）
- **從歷史學習**：把成功的計畫/工具序列存起來，遇到相似任務直接套用（少走冤枉路、更省）。
- **預算感知**：每個任務有 token/時間/Z幣預算，engine 自己權衡深度 vs 成本（呼應免費優先＋按需升級）。
- **主動代理**：不等你開口——每天掃你的機會島/信箱/待辦，「今天有 3 件值得做的事」主動推給你（Opportunity Agent）。
- **串流部分成果**：邊做邊把中間結果吐給你看，不用等到最後。
- **工具自動發現**：從一個 API 文件/OpenAPI 自動生成可用工具。
- **可觀測性**：每個任務的計畫樹、每步證據、成本、失敗原因都可回放（信任 + 除錯）。

> 一句話：**先做 L1（拆解）＋ L2（真瀏覽器/沙盒）**，這兩步就能把「像玩具」變「能交付專案」；L3–L5 再把可靠度往上推。我們的差異化仍是第一方生態（懂你、機會島閉環），別家 claw 有再強的引擎也沒有你的資料。
