# docs 目錄索引

分類整理（2026-07-13）。找東西看這裡。

| 資料夾 | 放什麼 |
|---|---|
| `worklog/` | 每日工作日誌 `daily_works_*.md`（收尾前先更新這裡再 commit）+ handoff 上下文 |
| `todo/` | **待辦統一放這**：`todo_list_0713.md`（最新總表）、MASTER_TODO、BACKLOG、ROADMAP 等 |
| `island/` | 分身島 × 機會島規劃：`分身島.md`、`機會島.md`（總表）+ `agent_*_plan.md`、`opportunity_island_spec.md` |
| `setup/` | 部署/整合設定指南：金流(Stripe/payments)、LINE、GA4、cron、N8N、AI models、free APIs… |
| `content/` | 內容/課程/辭典規格：`ch26_beginner_friendly_spec_v0.md`、`dictionary_plan.md`、lesson image spec/audit、language island、ASSETS |
| `product/` | 產品策略/構想/稽核：定價、AI 升級路線、UX audit、feature idea、綠寶建議、quest games、LINE bot plan |
| `handoff/` | 跨 AI 交接（Claude↔Codex） |
| `admin_upgrade/`、`creator/`、`grant/`、`ideas_os/`、`RULE/`、`待閱/` | 既有分類（後台升級、創作者島、補助、Ideas OS、規則、待閱來源腦力激盪） |
| （根目錄）`note.md`、`logerr.md` | 個人筆記/錯誤記錄，**保持 untracked**（.gitignore） |

> 移動檔案時記得更新引用：`CLAUDE.md`、寫檔的腳本（如 `_gen-image-audit.mjs`）、UI 顯示字串。
