## 0. 定位
> **你的數位分身，替你動手。** 交代目標，分身一步步規劃、用工具查資料/操作、記得你、跨裝置延續；關鍵動作先問過你才做。

- 差異化不是「操作能力最強」，而是**最透明、最可控、最適合新手、且長在 AI 島生態裡**（懂你的學習/作品/機會）。
- 護城河敘事（競賽用）：不做通用 Agent 模型，而是**面向初學者的安全操作層 + 教學層 + 任務模板平台**；底層模型可換，價值在**權限透明、步驟可視化、失敗可回復、免費優先省成本、用 Agent → 學會建 Agent**。
- 最能打的一句：現在的 AI 回答問題，下一代替人完成任務；擋住一般人用 Agent 的不是模型，是**不敢授權、不懂操作、無法判斷風險**——分身島讓每個人安全駕馭。

## 1. 真正的 Agent（vs 聊天）
聊天：`問題 → LLM 回答`。Agent：`理解目標 → 拆任務 → 選工具 → 執行 → 觀察 → 判斷成敗 → 失敗重試/換法 → 回報`。核心三保險：**權限確認、結果驗證、最大步數**——少一個就會無限點擊/重複寄信/連續重試。

## 3. 架構
```text
使用者（網頁 / 手機 / 語音）→ 自然語言目標
   ▼
Agent Core（server-side）：拆解(L1) → planner → 權限 → 執行 → 觀察 → 驗證/反思(L3) → 重試/下一步/完成
   │  ＋最大步數＋狀態機＋中止＋免費優先路由＋觀察正規化(省 token)
   ├ Tool Registry（風險 read/write/dangerous、平台、JSON schema）
   ├ Approval Engine（L0–L4）
   ├ Credential Broker（本機管密碼，Agent 只知「有無憑證」、看不到明文）
   └ 記憶（threads 前文 + memory 長期）
   ▼ 三種執行面
   A 雲端工具（server；web.search/fetch、算數/日期/JSON、島內、MCP）── 手機單獨可跑
   B 雲端沙盒（⬜ 臨時容器＝Phase E，沒 PC 也能跑本機類任務）
   C 本機 Bridge（桌面助手/Android：檔案/指令/瀏覽器；電腦沒開→排隊等上線）
```
**通訊**：Bridge↔雲端走 `agent_device_calls` 佇列＋輪詢（裝置無關，桌面/手機/Android 同一套）。正式版可加 WS 控制 + WebRTC 畫面串流 + 端到端加密。

**執行優先級（能走門別爬窗）**：`API/MCP` ＞ `結構化 UI（Playwright DOM / Windows UIA / macOS AX / Android AccessibilityService）` ＞ `視覺 Computer Use（截圖點座標，僅補位）`。

**觀察正規化（省 token）**：別把整個螢幕/DOM/檔案塞模型；只給「可互動元素＋文字＋recentActions＋screenshotRef（需要才要圖）」。

## 7. 引擎路線（六支柱 + L1→L5）
六支柱：手(工具)、腦(規劃)、眼(反思)、記憶、手煞車(人在迴圈)、調度(多代理)。
- **L1 拆解** ✅ · **L3 反思** ✅ · **L2 Tool First 省 token** ✅
- **L2 真手** 🚧：伺服器 Playwright 瀏覽器（不需你電腦、能點填登入跑 JS）＋ isolated-vm 真 JS 沙盒（需改 Docker 裝 Chromium/native module）＋ 外部容器（Python＝Phase E 雲端沙盒）。決策：先受限計算工具（已上）→ isolated-vm →容器，壞一個還有備用。
- **L4 技能合成** ⬜：agent 遇到沒有的能力當場建 skill 註冊。
- **L5 多代理/數位員工** ⬜：經理 agent 拆派給專才 sub-agent（研究/寫碼/設計/驗證）並行做、彙整。（已先出員工名冊 v1；平行調度需實測再上、不盲改核心迴圈）
- L5 之後：從歷史學習、預算感知、主動代理、串流部分成果、工具自動發現、可觀測性。

## 13. 競賽框架 / KPI / 風險（誠實）
場景挑三個：AI 學習助理／AI 開發助理／AI 數位生活助理。Demo 一條閉環：手機下令→電腦執行→AI 判斷→高風險前確認→回傳。
KPI：可完成任務 5–10 種、每種≥20 測、成功率≥80%、人工介入率/重試/平均步數/成本要算、**誤操作率趨近 0**（護城河）、使用者訪談 10–20 人。
三大風險：① 範圍失控（守核心 Windows+瀏覽器）② 成功率假象（Demo 一次≠產品）③ 權限信任（刪錯檔/發錯文＝電子內鬼）。競品問答：跟 Operator/Computer Use/Copilot/Zapier 差在「安全操作層＋教學層＋任務模板、模型可換」。
